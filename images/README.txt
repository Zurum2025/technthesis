IMAGES FOLDER
=============

Drop your project screenshots, logo and any photos here.

To use a real screenshot on the Portfolio page, replace a placeholder box.
Find a block like this in portfolio.html:

    <div class="shot">
      <div class="ph">...screenshot placeholder...</div>
    </div>

...and change it to:

    <div class="shot">
      <img src="images/my-screenshot.png" alt="My Project screenshot" />
    </div>

Recommended screenshot size: 1280 x 800 px (16:10). Optimised PNG/JPG/WebP.
